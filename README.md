# Jorden i rörelse

Interaktiva modeller till kapitlet **Jorden, landformer och landskap** (sidorna 54–97): jordklotets uppbyggnad, jordens inre och yttre krafter och hur isen formade landskapet.

Varje underrubrik har:

- en modell du styr med reglage eller **Spela**
- en enkel förklaring – *Som om du vore fem år*
- en lista att plugga på – *Mer utförligt*

Sidan har ljust och mörkt läge. Modellerna är förenklade och inte skalenliga.
